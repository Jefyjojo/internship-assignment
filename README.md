# Dr. Maya Reynolds, PsyD — Clinical Psychology Practice Website

A responsive private-practice clinical psychology website designed for **Dr. Maya Reynolds, PsyD** (Licensed Clinical Psychologist based in Santa Monica, California).

Built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.

---

## 🌿 Design & Aesthetic Direction

- **Calm, Editorial & Warm**: Tailored color palette avoiding generic templates.
  - Primary Background: Warm Ivory (`#F8F6F1`)
  - Secondary Background: Soft Beige (`#EFEAE2`)
  - Primary Text: Deep Charcoal (`#252525`)
  - Secondary Text: Muted Warm Gray (`#68645E`)
  - Accent: Muted Sage (`#7C8A78` / `#687565`)
  - Subtle Borders: `#DCD7CE`
- **Typography Hierarchy**:
  - Headings: *Cormorant Garamond* & *Playfair Display*
  - Body & UI: *Inter* & *Source Sans 3*
  - Line height: 1.65 relaxed
- **Layout**:
  - Generous whitespace and thin editorial dividers
  - Sticky navigation header with frosted glassmorphism on scroll (`backdrop-blur-md`)
  - Responsive mobile drawer navigation with accessibility considerations

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
